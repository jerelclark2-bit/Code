PROJECT 01 / COMPUTER VISION

BarnacleAI

Can a small CNN count the barnacles in a photograph? I trained a detector and a separate regression baseline, then built a review interface to see where the estimates break down.

The labels are incomplete, so results are comparisons against annotation proxies, not validated biological accuracy.
